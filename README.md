# 内容治理措施效果的分层实验分析

本地资料用于理解内容治理措施效果分析所涉及的记录关系。文件均为合成数据，标识符不对应真实个人、机构或账号。

## 目录

- `data/`：UTF-8 编码、首行为字段名的逗号分隔资料。空字段表示资料未提供，不代表数值为零或业务状态已否定。
- `analysis/`：可复算的分析包（仅标准库），按分配策略、可比范围、曝光机会与结果成熟时间解释措施效果。
- `tests/`：检查资料文件可读取和格式结构，并验证分析逻辑（状态分类、区间估计、复算一致性、更正后的运行比较）。

日期使用 ISO 8601 写法；时间字段为空时表示该记录没有提供时间。金额和计数字段以文本保存，具体解释须结合字段名及记录上下文。

## 运行与检查

需要 Python 3.11 或更高版本，无第三方运行依赖。

```bash
# 检查合成资料与分析逻辑
python3 -m unittest discover -s tests

# 对 data/ 运行完整分析，结果写入 runs/<运行ID>/
python3 -m analysis run --data data --out runs

# 只查看每个单位的状态核算表（不写运行目录）
python3 -m analysis states --data data

# 新一批观测或资料更正后：重新运行，再比较两次运行
python3 -m analysis compare runs/<旧运行ID> runs/<新运行ID>
```

每次运行保存 `manifest.json`（输入文件哈希）、`config.json`（分析配置）、
`results.json`（结构化结果，含每个单位的状态与来源行号）和 `report.md`（报告）。
同一输入 + 同一配置复算结果一致；输入更正后新旧运行的差异由 `compare` 逐项解释，
旧运行不被覆盖，据此作出的历史判断可以复查。

## 分析口径

- **按分配组别（ITT）**：以 assignments.csv 的分配为准比较处理/对照，不按是否曝光剔除单位；
  同一策略的不同版本（policy_versions.csv）拆分为独立版本段分别估计。
- **可比范围**：只在层（stratum）内两臂都有分配单位时给出对比；缺少对照的层明确列出，
  结论不外推。不同策略分配时间不重迭时，报告会提示跨策略比较存在时间混杂。
- **曝光机会**：曝光率作为分配后的中间变量单独报告（描述机制，不作效果估计）；
  跨策略曝光、有效期外曝光、无曝光却有结果等记录关系逐条列出。
- **结果成熟时间**：自首次曝光（无曝光则自分配）起算成熟窗口（默认 30 天，
  可用 `--maturity-days` 或配置文件调整）。窗口用于判定“无事件”是否最终；
  截止日前已观测到的成熟事件即计入。`--cutoff` 指定分析截止日，缺省取数据中的最大日期。
- **不确定度**：率差给 95% Newcombe 区间；未决结果（待复核/窗口未闭合/缺记录/截止日后）
  不进入主要率估计，其影响以 Manski 界限呈现；另给按场次聚类的稳健标准误作为敏感性。

### 结果状态定义

| 状态 | 含义 | 进入主要率估计 |
| --- | --- | --- |
| `mature_event` | 符合终点定义的最终事件（默认：成熟且已确认/已更正的投诉） | 分子 |
| `non_event` | 最终的非事件记录（如窗口已关闭的 no_record） | 分母 |
| `pending_review` | 有记录但分类或成熟度未最终确定 | 否（进入界限） |
| `window_open` | 观察窗口在截止日尚未关闭 | 否（进入界限） |
| `missing` | 窗口已关闭但没有任何结果行（缺失 ≠ 无投诉） | 否（进入界限） |
| `after_cutoff` | 记录的事件时间晚于分析截止日 | 否（进入界限） |

未曝光（`unexposed`）是曝光状态而非结果状态；未曝光单位仍按分配组别计入 ITT。

### 配置

`--config config.json` 可覆盖默认口径，未知键会报错。可用键见
`analysis/config.py` 的 `AnalysisConfig`（如 `event_kinds`、`final_review`、
`maturity_window_days`、`cutoff`、`z`、`min_clusters`）。配置随每次运行保存。

## 数据文件

- `data/assignments.csv`：分配记录（单位、策略、时间、层、组别）。
- `data/exposures.csv`：曝光记录（用户、场次、策略、时间、曝光次数）。
- `data/outcomes.csv`：结果记录（类别、成熟状态、复核状态）。
- `data/policy_versions.csv`：策略版本及有效期；同一策略不同版本是不同干预。

## 限制

分析包不预设措施有效或无效。主要因果限制（时间混杂、版本切换、层外推、
未决结果、聚类近似、按曝光条件化的偏差）由报告第 6 节按数据实况生成，
解读结论前请先阅读该节。
